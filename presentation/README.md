# ClearSignal WQ presentation

Public challenge deck:

- `ClearSignal-WQ-Deck.pptx`: editable seven-slide presentation;
- `ClearSignal-WQ-Deck.pdf`: public submission copy.

The deck uses screenshots from the local Streamlit prototype and the frozen evaluation figures documented in the project README. Synthetic scenario screenshots remain visibly labelled.

To rebuild the PPTX, install Node.js and `pptxgenjs`, then run:

```bash
node presentation/build_deck.cjs
```

Export the resulting PPTX to PDF without changing page size or fonts. Review all seven pages at 16:9 before publishing.
