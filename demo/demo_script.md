# ClearSignal WQ 演示脚本

目标时长：约 3 分 20 秒。操作提示使用中文；录制时只读英文口播。先运行 `./scripts/run_app.sh`，浏览器缩放保持 100%，从页面顶部开始。

## 0:00-0:25 问题

**操作：** 显示标题、站点和模式，不操作控件。

**English narration:**

“Small water teams receive thousands of sensor readings, but an unusual value does not explain what happened. It may be an environmental change, sensor drift, or a broken data link. ClearSignal WQ turns those signals into an evidence-based review queue.”

## 0:25-0:55 公开真实数据

**操作：** 保持 `Public real data`，指出来源、模型、事件队列和固定 commit，再点一个事件。

**English narration:**

“This mode uses public Logan River Observatory sensor data from a fixed pyhydroqc commit. The queue is generated by one deterministic pipeline. Each event keeps its source, run hash, affected sensors, evidence strength, and limitations.”

## 0:55-1:25 单传感器漂移

**操作：** Mode 切换到 `Single-sensor drift`，等待图表刷新，指向橙色状态和 pH 时间线。

**English narration:**

“Here I switch to a clearly labelled synthetic drift scenario. Only pH shows a sustained abnormal pattern and its reliability falls. The system does not escalate this as an environmental incident. It recommends cleaning, calibration, and an independent retest.”

## 1:25-1:58 多传感器相关变化

**操作：** Mode 切换到 `Correlated sensor shift`，指向绿色状态、三种传感器和高证据强度。

**English narration:**

“In the correlated-shift scenario, conductivity, dissolved oxygen, and pH change together. Multiple reliable sensors provide same-direction corroboration, so the event is triaged as a possible water-quality event. The next step is field retesting and, when justified, laboratory confirmation.”

## 1:58-2:28 数据缺口

**操作：** Mode 切换到 `Missing data interval`，指出数据完整性状态和检查链路建议。

**English narration:**

“A missing interval produces a different response. Data-integrity evidence takes priority, and the operator is asked to inspect timestamps, telemetry, and source records before rerunning the analysis. This prevents a communication failure from being presented as a water event.”

## 2:28-2:58 人工动作

**操作：** 在右侧选择合适动作，点击 `Save action`，展示仅当前会话保存的提示。

**English narration:**

“The operator can record a retest, calibration, data-link check, or escalation. This prototype keeps that action only in the demo session and never changes the source observations. Human review remains part of every decision.”

## 2:58-3:20 评价与限制

**操作：** 回到页面底部限制，停留两秒后结束。

**English narration:**

“On technician-labelled data-quality events, the selected rule baseline achieved full validation recall but still produced 7.3 invalid alerts per day. That false-alert burden is a real limitation. ClearSignal WQ is decision support, not regulatory or laboratory confirmation. The next step is a small field pilot with maintenance records and independent samples.”
